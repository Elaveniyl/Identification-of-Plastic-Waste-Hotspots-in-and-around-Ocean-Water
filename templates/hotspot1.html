Plastic Object & Debris Detection

Convolutional neural network classification targeting maritime plastic debris. Evaluates normalized imagery to differentiate plastics, metals, glass, paper, cardboard, and general marine waste.

Image Inference Console Inception-v3 Topology
Model Specifications
  • Architecture: Google Inception v3
  • Input Tensor: (1, 299, 299, 3)
  • Input Range: Normalized [-1.0, 1.0] float32
  • Target Classes: plastic metal glass cardboard paper trash
  • Inference Mode: Frozen Graph (retrained_graph.pb)
Scientific Limitations

Single-Object Constraint: The classifier was trained on isolated debris objects photographed under controlled lighting. Field imagery with heavy wave froth, turbidity, or multiple overlapping objects may yield lower confidence.

Geographic Decoupling: Image classification identifies material type only. Spatial coordinates and hotspot prioritization are computed independently via the GIS dataset.

Platform Compatibility: Native TensorFlow 1.x graph execution on modern Windows environments requires specialized containerization or registry long path support.
