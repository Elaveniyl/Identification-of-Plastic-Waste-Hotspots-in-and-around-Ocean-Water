Plastic Object & Debris Detection

Convolutional neural network classification targeting maritime plastic debris. Evaluates normalized imagery to differentiate plastics, metals, glass, paper, cardboard, and general marine waste.

Image Inference Console Inception-v3 Topology
Model Specifications
  • Architecture: Google Inception v3
  • Input Tensor: (1, 299, 299, 3)
  • Input Range: Normalized [-1.0, 1.0] float32
  • Target Classes: plastic metal glass cardboard paper trash
  • Inference Mode: Frozen Graph (retrained_graph.pb)
Scientific Limitations

Evaluation & Domain Shift: No accuracy evaluation was run. The model outputs the six TrashNet classes (paper, metal, cardboard, trash, glass, plastic) and appears to have been trained on a TrashNet-style dataset.

Out-of-Distribution Overconfidence: Sanity-check test runs on non-marine images (ocean.jpg seascape, Home.jpg banner, asd.jpg logo) were all labelled "plastic" at 70.33% to 97.11%, exhibiting overconfidence on out-of-distribution inputs. These runs were pipeline sanity checks only.

Geographic Decoupling: Image classification identifies material type only. Oceanic hotspot prioritization is driven independently by the 3,532 Lebreton et al. (2018) GIS survey records.
